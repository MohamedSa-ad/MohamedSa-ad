## 🚀 Featured Projects

### 1. NeuroInk – Handwritten Digit Recognizer
A web-based handwritten digit recognition application that uses a trained neural network to identify handwritten digits.

- Built using Python, TensorFlow/Keras, and Flask.
- Interactive drawing canvas for digit input.
- Displays predictions and confidence scores.
- Visualizes per-digit prediction probabilities.

🔗 [View Repository](https://github.com/MohamedSa-ad/NeuroInk--Hand-written-digit-recognizer)

### 2. Plant Disease Detector
An image classification application designed to identify plant diseases using a Convolutional Neural Network (CNN).

- TensorFlow and CNN-based classification.
- Image-based disease prediction.
- Desktop interface for interacting with the model.

### 3. Shopper Behavior Segmenter
A customer segmentation project that applies unsupervised Machine Learning to identify customer groups.

- Python and Scikit-learn.
- K-Means clustering.
- Customer behavior analysis.
- Interactive Tkinter interface.

### 4. AI Maze Solver & Treasure Hunt Simulator
A visualization-based project exploring classical AI search algorithms.

- Breadth-First Search (BFS).
- Depth-First Search (DFS).
- A* Search Algorithm.
- Python and Tkinter.

### 5. Office Commute Optimizer
A Python-based application designed to explore and optimize office commuting routes.

- Python and PyQt5.
- Route optimization concepts.
- Interactive desktop interface.
